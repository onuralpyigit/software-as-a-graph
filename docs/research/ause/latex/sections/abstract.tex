Automated code review and software quality evaluation rely largely on file- or class-level static analysis. In publish--subscribe architectures (ROS~2, DDS, MQTT), loose coupling hides indirect dependencies, creating an \textbf{Architecture-Code Gap}: clean unit-level metrics can coexist with single points of failure, co-location bottlenecks, and transport contract mismatches. We present \textbf{SaG-Prescribe}, pairing a deterministic \textbf{Diagnostic Pathway} with counterfactually verified refactoring. The pathway extracts a multi-layer dependency graph from Architecture-as-Code descriptors, folds code-level metrics into a \textbf{Code Quality Penalty}, computes a hierarchical \textbf{Reliability--Maintainability (RM)} attribution model informed by ISO/IEC 25010 and 25019, and runs a catalog of nineteen publish--subscribe anti-patterns. The prescriptive engine compiles findings into three graph-mutation operators---topic splitting, anti-affinity reallocation, and QoS hardening---admitting an edit only when its cascade-impact reduction exceeds simulator seed noise at every threshold.

Across eight synthetic scenarios (29--520 vertices, 12--300 applications) we report calibration evidence an accuracy-framed study would omit. Ranking saturates: the RM composite (mean Spearman $\rho = 0.485$) does not out-rank degree centrality ($0.519$). The catalog is a sensitive but chance-level component screen (recall $0.942$, precision $0.253$, $\kappa = -0.002$), because $98.4\%$ of its findings are edge- rather than component-scoped, and the Availability dimension is degenerate on the application-layer projection. Counterfactual verification admits 1128 of 1589 candidates ($71.0\%$). All seven scenarios improve on the framework's own risk index, but only five do under the independent cascade oracle (mean $+3.5\%$, $p = 0.22$), so the prescriptive effect is promising rather than significant---one of several limits we state explicitly, alongside a re-measurement of our own prior published correlation.
