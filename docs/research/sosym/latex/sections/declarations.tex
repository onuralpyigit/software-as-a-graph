\paragraph{Related publications and overlap.} The tool described here underlies the following publications by the authors. (i) \citet{yigit2025graph} (RASSE~2025, published) introduced an early graph model and criticality score. (ii) \citet{caliskan2026uyms} and \citet{ersen2026uyms} (UYMS~2026, published in Turkish) describe a CodeQL-based relation extractor with box-plot anomaly rules and an early version of the web platform. (iii) A manuscript under review at the \emph{Journal of Systems and Software}, ``Software-as-a-Graph: When Does Graph Learning Improve Cascade-Impact Ranking in Publish--Subscribe Systems?'', compares learned and analytical rankers; it shares the metamodel, scenario corpus and simulators with this paper. (iv) A manuscript under review at \emph{Automated Software Engineering}, ``SaG-Prescribe: Unifying Diagnostic Pathways with Counterfactual Refactoring for Automated Code Review and Software Quality Evaluation in Distributed Publish--Subscribe Systems'', evaluates the accuracy of the RM model and anti-pattern catalog and the yield of the refactoring engine. This paper describes the tool itself (modeling language, architecture, interfaces, extension points, engineering safeguards) and reports measurements produced for this paper from the current release; no table or figure is shared with (iii) or (iv). The formulas of the RM model (Appendix~\ref{app:formulas}) and the catalog definitions necessarily coincide with those in (iv), because they describe the same software.
