# Response to the 2026-10-08 referee report

This responds to [review_2026-10-08.md](review_2026-10-08.md): major comments M1–M9 and minor comments 1–18. The revision is on branch `jss-revision-round15`. That branch is the unmerged round-14 revision (`jss-revision-round14`, b3be1c4a) with `main` merged in.

## Scope

**The report reviewed `main`, which predates the round-14 revision.** About half of what it asks for was already done on the round-14 branch (Amendment 19, [experiment page](../experiments/amendments/a19-round14.md)):

- the tie-aware listwise loss;
- the learning curve over training architectures;
- GNNs given the declared rates;
- the sum-aggregation (GIN) control on both graphs;
- the corrected `I_dyn` headroom;
- the comparator reframing of the abstract and highlights.

Merging `main` brought in two further changes:

- the verified-reference cleanup (#104);
- the A11 rounding fix (+0.093).

Where the author's text pass on `main` (97464638) conflicted with round 14, the round-14 text was kept, and that pass's intent was ported where the report does not object to it.

**Not run (author's decision; text-only revision):**

- the confirmation corpus;
- a non-first-order oracle;
- a matched tuning budget, and R-GCN or Simple-HGN arms;
- a second modeler, an automatic extraction or fault injection;
- measured energy.

**Title.** The advisor's title is kept; the scope statement carries the restriction instead.

**New in this pass.**

- Text edits in §§1.3, 2.3, 4.2–4.4, 5.3, 6.1–6.4, 7.1–7.5 and 8.
- A derivation of Eq. 7 in Supplementary §S42.
- A [min, max] column in Table 9 and its reconciler check.
- Four new references, each checked against Crossref.
- A renderer fix for figure captions.
- `reconcile_manuscript.py` now checks 2,032 figures (2,016 before) with 0 mismatches.

**One correction found while answering m6.** The paper described the auxiliary target $I^*_R$ as "the reliability component the same simulator run records". The LOSO harness (`reproduce/main_table.py:_parse_failure_impact`) actually fills that label column with `total_impacted_subscribers`: the number of subscribers the same $I^*$ run marks as impacted, normalized like the main label. §4.2 now says this.
