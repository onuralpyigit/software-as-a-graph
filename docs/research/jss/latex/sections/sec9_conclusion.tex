\section{Conclusion}
\label{sec:9}

Software-as-a-Graph (SaG) bridges the Architecture--Code Gap in decoupled distributed systems by demonstrating that cascading-failure impact can be accurately identified and ranked prior to deployment directly from configuration manifests. By formalizing publish--subscribe semantics into an explicit logical dependency graph (\texttt{DEPENDS\_ON}), SaG reveals previously hidden failure paths arising from sequential backpressure and simultaneous blasts across shared infrastructure.

Our empirical evaluation establishes the decisive advantages of explicit dependency derivation. Under leave-one-scenario-out cross-validation across twelve unseen synthetic architectures, counting an application's direct dependents (\texttt{InDeg}, formalizing publish--subscribe afferent coupling) achieves Spearman $\rho = 0.764$, outperforming traditional closed-form centrality on all twelve held-out architectures ($+0.211$, Holm $p = 0.002$). Furthermore, counting transitive dependents transfers zero-shot to models inspired by five real-world open-source systems with exceptional accuracy ($\rho = 0.938$, $\rho_{>0} = 0.871$, PR-AUC = $0.933$) without any training. Crucially, evaluation against an independent discrete-event queue-flow simulator ($I_{\text{dyn}}$, $\rho = 0.610$; $+0.217$ over centrality) and multi-criteria failure simulation ($I_{\text{comp}}$, $\rho = 0.650$) confirms that this predictive power reflects genuine distributed message dynamics rather than reachability simulator artifacts.

Rigorously benchmarking graph neural networks against transparent structural baselines provides an essential insight for software engineering: once the architectural representation is made explicit, lightweight structural counting achieves parity with complex graph attention networks ($\rho = 0.748$), while avoiding the severe optimization instability of parameter-heavy relational typing and the substantial latency of neural feature extraction (median $5.6\times$ slower than direct simulation). For software engineering practice, SaG establishes a practical two-tier taxonomy: sub-millisecond manifest linting serves as an instantaneous, computationally sustainable pre-deployment gate in CI/CD pipelines, while SaG's ISO/IEC 25010 explanation layer delivers actionable remediation guidance to harden modern event-driven architectures.
