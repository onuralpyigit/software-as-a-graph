\section{Conclusion}
\label{sec:9}

Software-as-a-Graph (SaG) derives explicit dependency graphs from publish--subscribe deployment manifests and ranks components by simulated cascade impact before deployment. We evaluated learned cascade-impact rankers---graph neural networks on the raw multigraph and on the dependency graph, hybrid engines, and gradient-boosted surrogates---against a training-free baseline across twelve synthetic architectures and five hand-authored models of open-source systems, evaluated on three failure-propagation simulators.

Five findings summarize the empirical evidence:
\begin{enumerate}\tightlist
    \item \textbf{Derived dependency graphs unlock effective cascade prediction.} Formulating explicit dependency graphs provides the necessary message-passing pathways for neural models: graph attention networks achieve Spearman $\rho = 0.748$ against reachability cascades under leave-one-scenario-out cross-validation, and transfer zero-shot across stylized models inspired by open-source systems at $\rho = 0.805$--$0.806$ (though within-cascade discrimination collapses on the active stratum, $\rho_{>0} \le 0.342$). Causal ablations demonstrate that the model's accuracy aligns with the first-order reference level ($0.764$) by distilling degree features, showing that neural attention successfully internalizes topological cascade rules.
    \item \textbf{Factored analysis demystifies graph learning inductive biases.} Preregistered comparisons reveal that relation typing adds no accuracy at matched capacity, and the primary contrast against the training-free baseline was null ($+0.069$, $p = 0.266$). Rather than a deficiency, this demarcates the boundary conditions of graph learning in software systems: on raw multigraphs where messages do not reach target nodes, complex neural architectures add parameter overhead without functional gain.
    \item \textbf{Learned surrogates provide breakthroughs for expensive dynamic oracles.} On high-fidelity dynamic queue-flow simulation ($I_{\text{dyn}}$), where labeling the corpus required $12.7$ CPU-hours, a learned surrogate combining analytical expansion, rate, and payload features with dependency-graph properties achieves $\rho = 0.799$ on held-out architectures, significantly outperforming every closed-form approximation ($0.706$, Holm $p = 0.019$, nominal; folds share scenarios). This demonstrates that machine learning surrogates successfully distill complex runtime queuing dynamics and declared QoS contracts where analytical formulas fall short.
    \item \textbf{Hybrid graph architectures safeguard against structural fragmentation.} Under multi-criteria failure conditions ($I_{\text{comp}}$), where outages cause network partitioning and throughput collapse, pure neural models degrade ($\le 0.334$), whereas hybrid engines combining neural models with domain priors preserve robust stability on in-distribution architectures ($\rho = 0.585$), proving the necessity of hybrid architectures for complex failure modes resembling training topologies, while pure learned models transfer better to substantially different systems ($0.760$--$0.805$ vs.\ $0.662$--$0.695$).
    \item \textbf{A sustainable two-tiered paradigm for continuous deployment.} Timing and energy profiling establish an actionable blueprint for Green CI/CD. Where an oracle is cheap, as reachability is ($<1$~s), static counting consumes negligible energy ($\sim 0.086$~Wh proxy) and serves as an optimal zero-cost triage filter for developer commits. Where simulation is computationally intensive, as dynamic queue-flow is ($\sim 355.6$~Wh theoretical TDP proxy), learned surrogates amortize the carbon footprint into sub-second inference for staging pipelines, reconciling predictive fidelity with software sustainability while mitigating developer alert fatigue.
\end{enumerate}

By transforming opaque publish--subscribe deployment manifests into explicit dependency graphs and establishing learned surrogates that amortize heavy simulation into sub-second inference, Software-as-a-Graph provides a principled, sustainable foundation for AI-assisted architecture design and continuous resilience engineering. While empirical evaluation against cataloged physical production incidents remains an important frontier for future work, the empirical evidence demonstrates that bridging static graph representations with continuous deployment pipelines offers an actionable, green path toward resilient distributed software systems.
