Publish--subscribe middleware underpins modern distributed systems but conceals cascading failure paths behind decoupled topic abstractions. Software-as-a-Graph (SaG) bridges this Architecture--Code Gap by modeling event-driven architectures as typed multigraphs and deriving explicit dependency flows directly from deployment manifests. We evaluate learned cascade-impact rankers---graph neural networks, hybrid engines, and dynamic surrogates---across twelve synthetic architectures under leave-one-scenario-out cross-validation and zero-shot on five stylized open-source systems against three multi-oracle failure simulators.

Derived dependency graphs unlock effective learned ranking: graph attention networks achieve $+0.08$ to $+0.11$ gains over raw multigraphs, reaching Spearman $\rho = 0.748$. That is level with, but not equivalent to, the number of direct dependents ($0.764$), a reference that restates the reachability simulator's first wave, resting on the degree features the networks receive. Crucially, on dynamic queue-flow simulation costing $12.7$ CPU-hours ($\sim 355.6$~Wh theoretical TDP proxy), a learned surrogate over dependency features ranks held-out architectures above every closed-form approximation ($0.799$ against $0.706$), significantly outperforming analytical baselines ($+0.094$, $p = 0.019$, nominal; folds share scenarios) and enabling Green CI/CD by amortizing expensive simulation into sub-second inference. Under multi-criteria fragmentation, hybrid models maintain robust resilience on training-resembling distributions ($\rho = 0.585$ vs.\ $\le 0.334$), while pure learned models transfer strongly to unfamiliar systems ($\rho = 0.805$ vs.\ $0.662$--$0.695$), though active-stratum ranking remains challenging ($\rho_{>0} \le 0.342$). These empirical breakthroughs establish an actionable, sustainable two-tiered paradigm: instant topological counting for commit-stage triage, and learned surrogates for staging verification.
