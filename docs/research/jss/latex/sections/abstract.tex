Assessing distributed system dependability before deployment is hindered by absent runtime telemetry and static code analysis's blindness to communication topology. We present Software-as-a-Graph (SaG), a static system analysis framework that constructs typed multigraphs from Architecture-as-Code manifests across five entity types. SaG pairs two parameter-independent pathways: a relation-specific Heterogeneous Graph Transformer (HGT) with Quality-of-Service (QoS) edge encodings to forecast cascading failure blast radii, and an interpretable ISO/IEC 25010 layer that attributes fragility to Availability (single points of failure) or Fault Tolerance (cascade hubs) to guide targeted repairs.

Across eleven synthetic scenarios and five open-source reference systems (Autoware.universe ROS~2, GCP Online Boutique, Train-Ticket, Home Assistant, EdgeX Foundry), empirical results show: (1) relation typing yields a small but exceptionally consistent advantage over homogeneous learning on a shared native substrate, with matched training sets and model selection --- under distribution shift the typed model leads by $\Delta\rho = +0.082$ ($0.659$ vs.\ $0.577$), winning \emph{all twelve} folds ($p = 0.0005$), and the unweighted pair replicates this exactly ($+0.064$, 12/12, $p = 0.0005$), while in-distribution the margin is $+0.088$ (6/7, $p = 0.047$); (2) against a training-free QoS-weighted centrality baseline the learned model does \emph{not} establish an advantage: fixed-configuration ranking gives $+0.058$ (9/12, $p = 0.204$) and nested cross-validated selection $+0.115$ (10/12, $p = 0.052$), with critical-set identification likewise inconclusive ($F_1@K = 0.439$ vs.\ $0.375$; 7/12 folds, $p = 0.23$); (3) ablating the per-dimension QoS edge encodings leaves ranking accuracy unchanged ($-0.005$, $p = 0.68$) but halves seed-to-seed variance, so their contribution is training stability rather than accuracy; (4) the deterministic explanation layer ranks five open-source reference systems at $\rho = 0.514$--$0.800$, with EdgeX Foundry clearing all five quality release gates across all five seeds (100\% pass rate) while the remaining architectures fail strict threshold gates, and no learned model was evaluated there; and (5) an HGT forward pass takes $43.7\,\text{ms}$ for 2{,}000 components, with the full gate executing in $0.02$--$27.4\,\text{s}$. The two folds on which the learned model loses to the baseline share a label-free signature --- its own predictions collapse toward a constant --- so the failure is detectable at inference time. Training a neural model is thus justified by relational attention, per-relationship criticality, and standards-grounded attribution, not by ranking accuracy alone.
