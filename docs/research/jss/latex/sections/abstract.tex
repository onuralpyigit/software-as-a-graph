Publish--subscribe middleware obscures the paths through which failures propagate, yet architects must identify critical components before deployment, when no telemetry exists. We present Software-as-a-Graph (SaG), which derives explicit dependency graphs from deployment manifests to investigate when graph learning improves cascade-impact ranking. We compare graph neural networks, hybrids, and analytical and learned simulator approximations with training-free rankings on twelve synthetic architectures under leave-one-scenario-out evaluation against three failure simulators, and zero-shot on five hand-authored models of open-source systems. A reference criterion distinguishes rankings that restate a simulator's propagation rule from those that predict it.

On a reachability simulator, graph attention on the derived dependency graph reaches Spearman's $\rho = 0.748$, $+0.072$ above the same model with reverse edges on the raw multigraph, whereas on that graph the registered primary contrast against a training-free baseline was null. The learned model is matched by counting direct dependents ($\rho = 0.764$), suggesting little predictive signal beyond explicit dependencies. For a queue-flow simulator requiring $12.7$ CPU-hours to label the corpus, a rate-weighted first-order approximation reaches $\rho = 0.830$ in milliseconds, matching or exceeding a learned approximation trained on simulator labels ($\rho = 0.799$; exploratory). Hybrids that correct a closed-form prior significantly outperform the training-free baseline but not their base learners, and learned models transfer zero-shot better than that baseline ($\rho \approx 0.81$ vs.\ $0.53$), although dependency counts still rank higher.

All findings are conditional on simulation fidelity. In this simulated corpus, representation mattered more than model complexity, highlighting the importance of deriving meaningful dependency representations and evaluating learned methods against analytical alternatives aligned with the simulator.
