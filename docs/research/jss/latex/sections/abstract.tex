Modern asynchronous publish-subscribe and event-driven architectures decouple components across space and time, but conceal failure paths behind message brokers and topics. Whether graph representation learning can reliably forecast cascading failure blast radii from pre-deployment Architecture-as-Code manifests without runtime telemetry remains an open empirical question. This study investigates the empirical viability and architectural boundaries of heterogeneous graph learning for static dependability analysis through Software-as-a-Graph (SaG), an experimental framework transforming manifests into typed multigraphs. We evaluate a relation-specific Heterogeneous Graph Transformer with Quality-of-Service edge encodings (HGT-QoS) against closed-form network baselines, paired with an interpretable ISO/IEC 25010/25019-grounded structural attribution layer.

Evaluation across twelve inductive scenarios and five open-source systems reveals three primary empirical boundaries. First, the learned model does not achieve a statistically significant ranking advantage over an unparameterized QoS-weighted centrality baseline ($\rho = 0.638$ vs. $0.553$, $p = 0.151$). Second, relational typing and continuous QoS encodings act as empirical substitutes rather than complements (interaction $-0.199$, negative on 12/12 folds, $p = 0.0005$), providing redundant relational cues against a predominantly topological simulation target. Third, on the components that actually propagate failures every predictor loses most of its correlation, and only the typed learned model remains positive ($\rho_{>0} = +0.281$, against $-0.055$ to $-0.092$ for the training-free baselines) --- a margin that establishes relational learning as the only approach retaining active-stratum signal, without being large enough to establish transfer, and one that still inverts on a synchronous RPC call tree. Computationally, while neural inference requires only $56\,\text{ms}$, deterministic feature extraction renders cold static analysis roughly seventeen times slower than direct discrete-event simulation ($80.6\,\text{s}$ vs. $4.8\,\text{s}$). These findings establish that unparameterized QoS-weighted centrality provides a competitive training-free baseline, that relational typing confers diminishing returns when QoS is present, and that topological feature extraction forms the principal computational bottleneck in pre-deployment static analysis.
