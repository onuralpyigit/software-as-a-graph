The three real-world architectures are hand-transcribed from open-source repositories using dedicated architectural adapters.

\subsection{Baselines and Evaluated Predictors}
\label{sec:6.2}

We compare five primary predictor configurations:
\begin{enumerate}
    \item \textbf{Topo-BL:} Unweighted structural centrality (betweenness centrality and articulation point scoring).
    \item \textbf{Topo-QoS:} QoS-weighted topological centrality baseline.
    \item \textbf{RM / $Q(v)$:} Deterministic hierarchical quality attribution baseline (Section~\ref{sec:4}).
    \item \textbf{GL / GL-QoS:} Homogeneous Graph Attention Networks (GAT) \cite{velickovic2018graph} trained on the flattened, untyped graph projection.
    \item \textbf{HGL / HGL-QoS:} Relation-specific Heterogeneous Graph Transformers (Section~\ref{sec:5}).
\end{enumerate}

\subsection{Evaluation Metrics and Protocols}
\label{sec:6.3}

\begin{itemize}
    \item \textbf{Ranking Accuracy:} Spearman rank correlation ($\rho$) and Kendall's tau ($\tau$) between predicted rankings and ground-truth simulated impact $I^*(v)$.
    \item \textbf{Critical-Set Identification:} $F_1@K$, Precision@$K$, and Recall@$K$ for top-$K$ critical components, where $K = \lceil 0.20 \cdot |V_{\text{app}}| \rceil$.
    \item \textbf{Statistical Significance:} Paired Wilcoxon signed-rank tests \cite{wilcoxon1945individual} ($p < 0.05$) and bootstrap 95\% confidence intervals ($B = 2,000$) \cite{efron1993introduction,spearman1904proof}.
\end{itemize}

\subsubsection{Evaluation Protocols}
\begin{itemize}
    \item \textbf{In-Distribution Evaluation:} 60\% train / 20\% validation / 20\% test node splits pinned by node identity within each scenario, evaluated over five random seeds $\{42, 123, 456, 789, 2024\}$.
    \item \textbf{Inductive Leave-One-Scenario-Out (LOSO):} Models are trained on six scenarios and evaluated zero-shot on the seventh unseen scenario to test out-of-distribution generalizability.
    \item \textbf{Real-World Architectural Transfer:} Evaluating zero-shot transfer on authentic open-source architectures.
\end{itemize}
