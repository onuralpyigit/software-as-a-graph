\smallskip\noindent\textbf{Data Availability.} The complete replication package---including synthetic scenario datasets, generator configurations, simulation harnesses, real-world architecture adapters, trained model checkpoints, and all analysis scripts---is openly available on Zenodo under DOI \href{https://doi.org/10.5281/zenodo.14922108}{10.5281/zenodo.14922108} and cited as \cite{sag-replication-package} in compliance with Option C of the Elsevier research data policy. The synthetic corpus is regenerable: each dataset carries its random seed and SHA-256 cryptographic digest in a committed manifest, with automated tests asserting byte-identical regeneration from configuration files (Section~\ref{sec:6.1.repro}). The scenario corpus, the generator configurations and every analysis and figure script are in the source repository; the measurement artifacts those scripts read --- the JSON results of each evaluation run --- ship in the replication package rather than the repository, and must be restored alongside it to re-derive the tables. Every table and figure in this paper is produced deterministically from those artifacts rather than transcribed by hand, and a released script (\texttt{reproduce/reconcile\_manuscript.py}) re-checks all 177 reported table figures against the artifact that produced each one, failing if any has drifted or if any artifact predates the corpus it describes.
