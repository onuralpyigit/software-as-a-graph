# Abstract

Modern asynchronous publish–subscribe systems separate components in space and time, but they also obscure how failures spread across components. A key challenge for reliable distributed systems is whether graph representation learning can predict failure impact directly from Architecture-as-Code manifests, without runtime data. In this study, we introduce Software-as-a-Graph (SaG), a static analysis tool that turns deployment manifests into typed multigraphs to help decide when and where to use relational graph learning. We compare a Heterogeneous Graph Transformer with Quality-of-Service edge encodings (`HGT-QoS`) to traditional network baselines, and include an interpretable ISO/IEC 25010/25019 attribution layer for diagnostic refactoring.

We tested our approach in twelve different scenarios and five real open-source systems. The results show that relational typing and continuous QoS encodings work as substitutes, not as complements. `HGT-QoS` outperformed untyped networks in new situations ($\Delta\rho = +0.234$, reaching $\rho = 0.638$). In zero-shot transfer tests, `HGT-QoS` accurately tracked how failures spread in asynchronous event meshes, but performed worse in synchronous RPC call trees where timeouts move up the stack. Since the learned ranking is similar to a simple QoS-weighted centrality baseline, we propose a Dual-Engine Consensus Protocol. Using both models together gives reliable critical-set triage, while the ISO/IEC attribution layer helps find structural root causes for targeted fixes. Although extracting features can take up to 79.3 seconds, which is 2 to 18 times longer than in-process simulation, neural inference is much faster at 56 milliseconds. This shows that static gating can avoid the need for live staging clusters and allows for sub-second gating when combined with incremental topology caching in continuous integration pipelines.

**Keywords:** Heterogeneous graph neural networks; distributed systems dependability; publish–subscribe architecture; cascading failures; static system analysis; explainable AI
