# Abstract

Modern asynchronous publish–subscribe architectures decouple components across space and time, but conceal cascading failure paths behind message brokers and topics. Whether graph representation learning can forecast failure blast radii directly from pre-deployment Architecture-as-Code manifests, without runtime telemetry, is a critical challenge for dependable distributed systems. This study presents Software-as-a-Graph (SaG), a static analysis framework that transforms deployment manifests into typed multigraphs to evaluate when and where relational graph learning should be deployed. We assess a Heterogeneous Graph Transformer with Quality-of-Service edge encodings (`HGT-QoS`) against closed-form network baselines, paired with an interpretable ISO/IEC 25010/25019 attribution layer for diagnostic refactoring.

Empirical evaluation across twelve inductive scenarios and five authentic open-source systems establishes that relational typing and continuous QoS encodings act as empirical substitutes rather than additive complements, with `HGT-QoS` achieving substantial out-of-distribution gains over untyped networks ($\Delta\rho = +0.234$, $p = 0.0005$, reaching $\rho = 0.638$). Zero-shot transfer demonstrates that `HGT-QoS` successfully captures multi-hop cascade propagation in asynchronous event meshes (e.g., ROS 2 Autoware $\rho_{>0} = +0.517$, Home Assistant $+0.702$), but inverts on synchronous RPC call trees where timeouts propagate backward up invocation stacks. Because learned ranking performs comparably to a zero-training QoS-weighted centrality baseline (`Topo-QoS`, $\rho = 0.553$), we operationalize our findings through a Dual-Engine Consensus Protocol: combining `HGT-QoS` and `Topo-QoS` concurrently provides robust, high-confidence critical-set triage, while the ISO/IEC attribution layer isolates structural failure root causes. Forward neural inference requires $56\,\text{ms}$, establishing pre-deployment static gating as an effective infrastructure-avoidance mechanism that eliminates live staging clusters in continuous integration pipelines.

**Keywords:** Heterogeneous graph neural networks; distributed systems dependability; publish–subscribe architecture; cascading failures; static system analysis; explainable AI
