# Abstract

Publish–subscribe middleware decouples components in space and time, concealing the paths along which cascading failures propagate. Identifying systemically critical components prior to deployment—before runtime telemetry or staging clusters exist—remains an essential challenge for software architecture dependability. We present Software-as-a-Graph (SaG), a static system analysis framework that models event-driven architectures as typed multigraphs and formally derives explicit logical dependency graphs directly from deployment manifests. Our evaluation demonstrates that deriving this explicit dependency projection unlocks highly accurate, pre-deployment cascading-failure impact ranking using simple, training-free structural metrics. Under leave-one-scenario-out cross-validation across twelve diverse synthetic architectures, counting a component’s direct dependents (`InDeg`, formalizing publish–subscribe afferent coupling) ranks simulated cascade impact at Spearman $\rho = 0.764$, beating closed-form centrality on all twelve held-out architectures ($+0.211$). On models inspired by five real-world open-source systems, counting transitive dependents reaches $\rho = 0.938$ without training ($\rho_{>0} = 0.871$, PR-AUC = $0.933$). Evaluated across independent simulation paradigms, dependency counting maintains strong predictive validity against an independent discrete-event queue-flow simulator ($I_{\text{dyn}}$, $\rho = 0.610$ on an $n=30$ candidate sample per fold; $+0.217$ over centrality) without architectural circularity, and against multi-criteria failure simulation ($I_{\text{comp}}$, $\rho = 0.650$). Rigorous benchmarking against graph neural networks reveals that graph attention networks on the dependency projection match the count ($\rho = 0.748$), while in standard untuned configurations on the sparse projection, parameter-heavy relational typing introduces optimization instability without exceeding transparent structural counts. Crucially, dependency counting executes in sub-milliseconds on configuration manifests, whereas neural feature extraction takes median $5.6\times$ ($2.0\text{–}17.7\times$) longer than in-process direct simulation ($I^*$). SaG establishes that formalizing architectural dependencies enables sub-millisecond, computationally sustainable reliability triage directly in CI/CD pipelines, providing an essential empirical benchmark for AI techniques in software architecture dependability.

**Keywords:** Dependency graphs; cascading failures; publish–subscribe; graph neural networks; software architecture; dependability; empirical study
