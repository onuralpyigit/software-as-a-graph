# Abstract

Modern asynchronous publish–subscribe architectures decouple system components across both space and time, yet they obscure cascading failure paths behind message brokers and topics. Determining whether graph representation learning can predict failure blast radii directly from pre-deployment Architecture-as-Code manifests, without relying on runtime telemetry, remains a significant challenge for ensuring dependable distributed systems. This study introduces Software-as-a-Graph (SaG), a static analysis framework that transforms deployment manifests into typed multigraphs to evaluate relational graph learning approaches. We compare the Heterogeneous Graph Transformer with Quality-of-Service edge encodings (`HGT-QoS`) against closed-form network baselines, with an interpretable ISO/IEC 25010/25019 attribution layer for diagnostic refactoring.

Empirical study across twelve inductive scenarios and five open-source systems indicates that relational typing and continuous QoS encodings function as empirical substitutes rather than additive complements. The `HGT-QoS` model produces significant out-of-distribution improvements ($\rho = $0.767$) over untyped networks ($\Delta\rho = +0.234$). Zero-shot transfer results show that `HGT-QoS` models multi-hop cascade propagation in asynchronous event meshes, while performance declines on synchronous RPC call trees, where timeouts propagate upward through invocation stacks. As learned ranking performs comparably to a zero-training QoS-weighted centrality baseline, these outcomes are operationalized via a Dual-Engine Consensus Protocol. Concurrent deployment of `HGT-QoS` and `Topo-QoS` allows robust, high-confidence critical-set triage, while the ISO/IEC attribution layer isolates structural failure root causes. Forward neural inference requires $56\,\text{ms}$, supporting pre-deployment static gating as an effective infrastructure-avoidance strategy that eliminates the need for live staging clusters in continuous integration pipelines.

**Keywords:** Heterogeneous graph neural networks; distributed systems dependability; publish–subscribe architecture; cascading failures; static system analysis; explainable AI
