# Abstract

Publish–subscribe middleware is fundamental to modern distributed systems; however, its decoupled topic abstractions frequently obscure cascading failure paths. To tackle this limitation, Software-as-a-Graph (SaG) models event-driven systems as typed multigraphs and extracts explicit dependency flows from deployment manifests. This study appraises learned cascade-impact rankers, including graph neural networks, hybrid engines, and dynamic surrogates, on twelve synthetic architectures using leave-one-scenario-out cross-validation. Additionally, these rankers are assessed in zero-shot settings on five stylized open-source systems with three multi-oracle failure simulators.

Utilizing derived dependency graphs improves the performance of learned ranking models. Specifically, graph attention networks achieve improvements of $+0.08$ to $+0.11$ over raw multigraphs, attaining a Spearman $\rho$ of 0.748. This outcome is comparable, though not identical, to using the number of direct dependents ($0.764$), which represents the initial wave in the reachability simulator and depends on the degree features provided to the networks. Notably, in a dynamic queue-flow simulation requiring $12.7$ CPU-hours (approximately $355.6$ Wh), a learned surrogate leveraging dependency features ranks held-out architectures more effectively than any closed-form method ($0.799$ vs. $0.706$). It also surpasses analytical baselines ($+0.094$, $p = 0.019$; folds share scenarios) and facilitates Green CI/CD by reducing simulation time to sub-second inference. When multi-criteria fragmentation arises, hybrid models preserve robustness on distributions similar to the training data ($\rho = 0.585$ vs. $\le 0.334$). In contrast, pure learned models generalize well to different systems ($\rho = 0.805$ vs. $0.662$–$0.695$), although ranking within active strata remains challenging ($\rho_{>0} \le 0.342$). The results support a practical, sustainable two-step approach: use instant topological counting for rapid triage at the commit stage and learned surrogates for verification during staging.

**Keywords:** Dependency graphs; cascading failures; publish–subscribe; graph neural networks; graph learning; software architecture; dependability; empirical study
