# Abstract

Publish–subscribe middleware decouples distributed components in space and time but conceals cascading failure paths, leaving architects without pre-deployment evidence on component criticality. Software-as-a-Graph (SaG) introduces a framework modeling event-driven systems as typed multigraphs and deriving explicit dependency flows from configuration manifests. We evaluate learned cascade-impact rankers—graph neural networks, hybrid engines, and dynamic surrogates—across twelve synthetic architectures under leave-one-scenario-out cross-validation and zero-shot on five stylized open-source models, against three simulated failure oracles.

Derived dependency graphs enable effective learned ranking: graph attention networks achieve $+0.08$ to $+0.11$ gains over raw multigraphs, reaching Spearman $\rho = 0.748$. That is level with, but not equivalent to, the number of direct dependents ($0.764$), a reference that restates the reachability simulator’s first wave, resting on the degree features the networks receive. Crucially, on dynamic queue-flow simulation costing $12.7$ CPU-hours ($\sim 355.6$ Wh theoretical TDP proxy), a learned surrogate over dependency features ranks held-out architectures above every closed-form approximation ($0.799$ against $0.706$), significantly outperforming analytical baselines ($+0.094$, $p = 0.019$) and enabling Green CI/CD by amortizing expensive simulation. Under multi-criteria fragmentation, hybrid models maintain stability ($\rho = 0.585$) where pure neural models collapse ($\le 0.334$). Zero-shot transfer reaches $\rho \approx 0.81$ on unseen stylized architectures, though active-stratum ranking is weak ($\rho_{>0} \le 0.342$). Our findings establish a sustainable two-tiered paradigm: lightweight topological counting for commit-stage triage, and learned surrogates for staging verification.

**Keywords:** Dependency graphs; cascading failures; publish–subscribe; graph neural networks; software architecture; dependability; empirical study
