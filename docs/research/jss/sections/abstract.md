# Abstract

Publish–subscribe middleware obscures failure propagation, yet architects must identify critical components before deployment without telemetry. We present Software-as-a-Graph (SaG), deriving explicit dependency graphs from manifests to evaluate whether and when graph learning improves cascade-impact ranking. We compare graph neural networks, hybrids, and analytical simulator approximations across twelve synthetic architectures under leave-one-scenario-out cross-validation against three failure simulators, and zero-shot on five stylized open-source system models. A reference criterion distinguishes rankings that restate a simulator’s propagation rule from those that predict it.

On a reachability simulator, graph attention on the derived dependency graph reaches Spearman’s $\rho = 0.748$, $+0.072$ above the same model with reverse edges on the raw multigraph, whereas on the raw multigraph the registered primary contrast against a training-free baseline was null. It is not distinguishable from counting direct dependents ($\rho = 0.764$), and its gain survives removing input features that compute part of the simulator. For a queue-flow simulator requiring $12.7$ CPU-hours to label the corpus, a rate-weighted first-order approximation reaches $\rho = 0.830$ in milliseconds, matching or exceeding a learned approximation trained on simulator labels ($\rho = 0.799$; exploratory). Learners that start from that approximation do not improve on it. Learned models transfer zero-shot better than the training-free baseline ($\rho \approx 0.81$ vs. $0.53$), although dependency counts rank higher.

All three simulators admit such approximations: under first-order propagation regimes, explicit dependency representation renders complex learning superfluous. Representation matters more than model complexity; learned methods must be evaluated against aligned analytical baselines.

**Keywords:** Dependency graphs; cascading failures; publish–subscribe; graph neural networks; graph learning; software architecture; dependability
