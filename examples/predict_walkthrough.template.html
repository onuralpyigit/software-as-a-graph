Predict Walkthrough

Predict answers one question: if this component failed, how far would the damage spread? It answers from structure alone, before anything runs. This page builds that answer for one small air-traffic system, first by counting, then with a trained model, and then checks both against simulation.

The same architecture is read two ways

Closed-form references read the dependency projection: who depends on whom once topics are folded away. The trained model reads the raw graph, with every node type and a QoS vector on each edge. In the diagram the selected component is outlined and the components that depend on it, directly or transitively, are shaded.

2 · counting

Four references need no training and run in under a millisecond. Each is a truncation of what the simulator itself computes, so they are baselines to beat, not discoveries.

3 · the trained model

HGT-QoS was fitted on twelve other systems and has never seen this one. It reads a feature row per node, passes messages along the typed edges, and returns three numbers: a composite criticality, plus reliability and maintainability heads. Five independently trained seeds are run to see how stable the answer is.

4 · the ranking

Every ranker orders the same seven components

Scores are on different scales, so only the order is comparable. The trained model's top three become the shortlist handed to Diagnose.

5 · two engines at once

Where the trained model and a structural baseline agree, and where they do not

The dual-engine mode runs HGT-QoS beside Topo-QoS, a betweenness baseline. Components in both top-K lists form the consensus set. Components whose ranks differ widely are escalated for a person to look at.

6 · checked against simulation

How each ranking compares with the impact it was meant to forecast

None of the rankers saw these numbers. I* is the cascade impact the fault injector measures when each component is failed in turn; ρ is the rank correlation over the six applications.

How this was produced. python examples/run_predict_walkthrough.py on examples/mini_atm.json: reference rankers from reproduce/referee_round7.raw_rankers, the trained model through Client.predict(mode="gnn", gnn_checkpoint=…) for five seeds, the dual engine through PredictionService.predict_dual, and labels from FaultInjector with five seeds.

Six applications are far too few to estimate accuracy: one swapped pair moves ρ by a tenth or more. The page shows how a prediction is assembled, not how good it is. For that, see the published leave-one-system-out results.
